# 🗓️ Optimum - プレミアム・スケジュール調整アプリ

「誰でも、どこでも、美しく」を実現する、モダンな日程調整ツール。

## 🚀 ワンクリック・デプロイ

このアプリを世界中に公開し、データベース（Supabase）を自動でセットアップするには、下のボタンから Vercel にデプロイしてください。

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2F%5Bあなたのユーザー名%5D%2Fschedule-app&env=NEXT_PUBLIC_SUPABASE_URL,NEXT_PUBLIC_SUPABASE_ANON_KEY&project-name=optimum-scheduler&repository-name=optimum-scheduler)

### 💡 公開手順（一番簡単な方法）

1. **GitHubにログイン**: このコードをGitHubのリポジトリとして保存します。
2. **Vercelと連携**: 上のボタン、または Vercel のダッシュボードから該当のリポジトリを選択します。
3. **Databaseの準備**: Vercel の「Storage」タブから、Supabase 連携をポチポチと進めるだけで環境変数が自動で入ります。

---

## ✨ 主な機能

- **直感的なカレンダー**: 日付をクリックするだけで候補日を複数選択。
- **詳細な時間指定**: 各候補日に「19:00〜」などの時間を個別に設定可能。
- **リアルタイム集計**: 送信された回答を即座に計算し、最適な日程をトロフィーアイコンで表示。
- **管理者メニュー**: 不要になったイベントや回答を簡単に削除。
- **プレミアムUI**: モスグリーンとナイトブルーを基調とした、モダンで美しいダークモードデザイン。

## 🛠️ スタック

- **Frontend**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Database**: Supabase
- **Icons**: Lucide React
- **Date Handling**: date-fns
